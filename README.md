# Kart Tabanlı Strateji Oyunu

## Tanıtım
Tarayıcıda çalışan, 3D, kart tabanlı gerçek zamanlı bir strateji oyunu; ekonomi ve üs geliştirme, otomatik asker savaşları ve kart destesi mekaniklerini birleştirir; tek oyunculu, bilgisayara karşı.

## Teknolojiler
- Three.js
- TypeScript
- Vite
- HTML5 & CSS3

## Çalıştırma
```bash
npm install
npm run dev
```

## Yayın
GitHub'da Settings > Pages > Source: GitHub Actions seçilir; main dalına push ile yayınlanır.

## Görseller ve Lisans
3D modeller basit geometrilerle kodla üretilir; harici model veya ses dosyası kullanılmaz.
